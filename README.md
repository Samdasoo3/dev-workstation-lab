# Development Workstation Lab

## 프로젝트 개요
Linux CLI, Docker, Git, GitHub를 활용한
개발 워크스테이션 구축 실습 프로젝트입니다.

## 개발 환경
- OS: Windows + WSL2 Ubuntu
- Shell: Bash
- Docker: 29.9.3
- Git: 2.53.0

## 주요 실습
- Linux CLI 파일 및 디렉터리 관리
- 파일 및 디렉터리 권한 변경
- Docker 이미지 및 컨테이너 관리
- NGINX 기반 커스텀 이미지 제작
- Docker 포트 매핑
- 바인드 마운트 변경 반영
- Docker 볼륨 영속성 검증
- Git 및 GitHub 연동

## 검증 결과
실제 명령어 출력과 스크린샷을 추가할 예정입니다.

## 트러블슈팅
WSL 초기 설정 및 Docker 권한 오류 해결 과정을 추가할 예정입니다.
